Multi-Tier Architecture

End-to-End Enterprise Flow

How the PayShield FinTech microservice is provisioned, deployed, and scaled.

1. Terraform IaC

Provisions AWS VPC, 2 Availability Zones, Security Groups, and IAM roles for PCI compliance.

2. CI & Ansible

Jenkins executes PyTest, builds non-root Docker images, pushes to DockerHub, and orchestrates nodes via Ansible.

3. Kubernetes K8s

Zero-downtime Blue/Green rolling updates, Horizontal Pod Autoscaling (3 to 10 pods), and NodePort 30080.
